# Immaterial Impulse

A Material 3 Expressive desktop for Hyprland, built on Quickshell. The full
README, with screenshots, is [.github/README.md](.github/README.md) — GitHub
shows it on the repository page.

```sh
curl -fsSL https://raw.githubusercontent.com/XephyLon/immaterial-impulse/main/get.sh -o /tmp/imi-get.sh && bash /tmp/imi-get.sh
```
